# Velo Atelier／疾輪工房視覺方向

## 可選視覺風格

| 編號 | 方向 | 特徵 | 適用情境 |
|---|---|---|---|
| 1 | 精密工業展示間 | 冷灰金屬、技術藍、模組化儀表 | 強調規格比較與工程可信度 |
| 2 | 高級自行車精品店 | 深色木質、暖光、低飽和材質 | 強調奢華選購與品牌敘事 |
| 3 | 義式競速海報 | 暖白紙張、賽車紅、強烈格線、編輯式排版 | 最適合鮮明展示客製公路車，已採用 |
| 4 | 現代車隊維修區 | 螢光點綴、碳纖黑、資訊密度較高 | 適合性能設定與競賽資料 |
| 5 | 日系機能型錄 | 大量留白、墨黑、精緻小字與物件攝影感 | 適合安靜、收藏導向的體驗 |

選定第 3 種「義式競速海報」。它以真實編輯設計常見的比例、格線與印刷色感取代泛用玻璃卡片、漸層光暈和過度圓角，降低 AI 產生介面的模板感。

## 核心色票

| Token | 色碼 | 用途 |
|---|---|---|
| Paper | `#F0E9DC` | 主背景，模擬暖白紙張 |
| Paper Light | `#F8F4EB` | 控制列與浮起區塊 |
| Ink | `#151412` | 標題、描邊與主要控制 |
| Ink Soft | `#5D584F` | 次要說明 |
| Corsa Red | `#A61E31` | 品牌線條、警示與預設色 |
| Pista Green | `#235D4A` | 狀態、正向重點與配色 |
| Azzurro | `#173F5F` | 冷色預設與資訊層次 |
| Brass | `#C5A45D` | 少量工藝點綴 |

介面對比以 Paper／Ink 為主，不以顏色作為唯一狀態訊號。使用者可選的車體色不受品牌色票限制，但色彩輸入旁必須保留文字標籤。

## 字體策略

- 介面標題：`Arial Narrow`、`Noto Sans TC`、`PingFang TC`、`Microsoft JhengHei` 的窄體感系統字體堆疊，使用高字重與緊密行距。
- 內文：系統無襯線字體，中文以 `Noto Sans TC`／`Microsoft JhengHei` 回退，確保各平台清楚可讀。
- 技術標籤：`Courier New` 等寬字體，使用大寫英文、小尺寸與適度字距。
- 車架文字：提供 Corsa、Grotesk、Serif、CJK 四組 Canvas 字體堆疊；中文、英文與日文都必須有系統回退。
- 不依賴遠端字型，避免載入延遲及授權不明。

## 元件規格

- 主要版面：桌機為品牌欄／3D 舞台／控制台三欄；平板隱藏品牌敘事並保留舞台與控制台；手機改為單欄長頁。
- 分隔線：1px Ink、低透明次要線；不使用無目的陰影卡片。
- 按鈕：方角或至多 2px 圓角，最小觸控高度 44px；選取狀態使用反相底色、勾記或文字狀態。
- 規格選項：兩欄格狀按鈕；名稱與一句影響說明同時呈現。
- 色彩控制：原生色彩輸入搭配零件名稱，不只顯示色塊。
- 3D 舞台：背景保留印刷格線、比例尺及斜向紅線；模型本身是唯一高光澤焦點。
- 零件說明：固定放在控制台脈絡中，顯示名稱、類別與用途，不以遮住模型的浮動提示呈現。
- 焦點：2px Corsa Red 外框及間距，所有按鈕、輸入與 Canvas 可辨識。

## 動畫原則

- 旋轉與狀態更新使用 120–220ms；不使用彈跳、漂浮或永續呼吸光。
- 自動旋轉速度應足以觀察幾何，不製造眩暈；由使用者主動切換。
- `prefers-reduced-motion: reduce` 時停用自動旋轉並縮短非必要轉場。
- 規格切換直接更新幾何與材質，不以全畫面淡出掩蓋延遲。
- 拖曳使用阻尼提供機械重量感；觸控與滑鼠回饋一致。

## 禁止事項

- 禁止玻璃擬態、霓虹紫藍漸層、滿版光暈、過量膠囊按鈕與無意義 emoji。
- 禁止偽造真實品牌 Logo、車隊塗裝、贊助商標誌或未授權產品模型。
- 禁止把所有內容放入等尺寸卡片，或用裝飾取代清楚的資訊層級。
- 禁止低對比灰字、只靠顏色表示選取、移除鍵盤焦點或強迫播放動態。
- 禁止為了「高擬真」加入沒有用途的重型圖片與影片素材。
