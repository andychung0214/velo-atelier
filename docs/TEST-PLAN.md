# Velo Atelier／疾輪工房測試計畫

## 測試目標

驗證靜態網站能在現代桌機與行動瀏覽器載入 three.js 公路車，讓使用者安全地更換規格、配色、字體與車架文字，並可旋轉、縮放、點選零件及保存配置。自動測試使用 Node.js 內建 `node:test`，不引入大型測試框架。

## 自動測試

執行：

```bash
npm install
npm run verify
```

| 測試檔 | 範圍 | 主要案例 |
|---|---|---|
| `catalog.test.js` | 零件及預設目錄 | 唯一 `partId`、完整用途、選項數量、八組色彩、三組預設 |
| `config.test.js` | 配置正規化 | 合法覆寫、未知值回退、不可變更新、色碼與文字清理 |
| `storage.test.js` | 本機儲存 | 版本、損壞資料、不可用儲存空間、只清除專案鍵值 |
| `text.test.js` | 車架文字 | 中文／英文／日文、Unicode 長度、控制字元、字體回退 |
| `scene-contract.test.js` | 3D 模型 | 真實車架比例、零件角色與安裝位置、輪組與煞車切換、材質更新、點選高亮、響應式相機 |
| `structure.test.js` | HTML／CSS 契約 | 語意區域、SEO、固定 three.js 版本、焦點、減少動態效果 |
| `ui.test.js` | 控制台模型 | 規格、色彩、字體、預設與目前選取狀態 |
| `delivery.test.js` | 交付品質 | 必要文件、安全靜態路徑、MIME、首頁與 404 |

## 功能測試清單

- [ ] 首次進站載入 Corsa Rosso，3D 舞台沒有持續載入或錯誤提示。
- [ ] 三個工房預設會同步更新所有規格、顏色、字體和車架文字。
- [ ] 競賽、空力、耐力三種車架幾何會改變可辨識的車管配置。
- [ ] 碟煞與 C 夾煞互斥，不同煞車模型不會同時顯示。
- [ ] 淺框、刀輪、後板輪會更新前後輪；後板輪只套用於後輪。
- [ ] 機械變速與電子變速會更新控制線／電變細節。
- [ ] 經典彎把與空力一體把會更新座艙輪廓。
- [ ] 八個色彩控制分別更新車架、前叉、輪組、煞車、傳動、把帶、座墊與文字。
- [ ] 中文、英文、日文與混合車架文字都能顯示；清空時貼花隱藏。
- [ ] 四種字體切換後文字風格可辨識且沒有缺字方塊。
- [ ] 點選各主要零件會高亮正確群組，說明面板顯示名稱與用途。
- [ ] 側視角呈現雙三角車架、接近水平上管、短頭管與低於輪軸的五通，不出現過長輪距或塔狀頭管。
- [ ] 水壺架貼近下管；碟煞卡鉗靠近輪轂，C 夾煞位於前叉冠與後上叉橋。
- [ ] 拖曳、滾輪、雙指縮放、重設視角及自動旋轉正常。
- [ ] 重新載入後配置恢復；重設全部只清除疾輪工房配置。
- [ ] 模擬 WebGL 失敗時顯示可理解的降級提示，控制台仍可閱讀。

## 行動裝置與 RWD

| 尺寸／環境 | 檢查項目 |
|---|---|
| 1440×900 桌機 | 三欄完整、舞台優先、控制台可獨立捲動、整車在初始視角內 |
| 1280×720 桌機 | 不產生水平捲動、主要控制仍可見、3D 不被控制台覆蓋 |
| 834×1112 平板 | 舞台與控制台雙欄、品牌側欄收合、整車完整、可觸控操作 |
| 390×844 手機 | 單欄、Canvas 375×439 左右、整車約佔舞台寬度 50–75% 且有安全邊界、控制高度至少 44px |
| Android Chrome | 單指旋轉、雙指縮放、原生色彩控制與文字鍵盤可用 |
| iOS Safari | 觸控不造成整頁誤縮放，Canvas 不阻止控制台正常捲動 |
| 橫向手機 | 舞台不溢位，控制台仍可向下捲動完成所有設定 |

三種基準尺寸都要記錄 `innerWidth` 與 `document.body.scrollWidth`；扣除瀏覽器捲軸後不得有額外水平溢位。

## 無障礙測試

- [ ] `Tab` 可依視覺順序到達重設、自動旋轉、所有設定、Canvas 與重設全部。
- [ ] 焦點外框在暖白及黑色背景上都清楚可見。
- [ ] Canvas 具有操作名稱、操作提示關聯與鍵盤方向鍵／`Home` 支援。
- [ ] 狀態變更透過 `aria-live` 播報，不搶走目前焦點。
- [ ] 規格按鈕具有可程式判讀的目前選取狀態。
- [ ] 色彩輸入、文字輸入與字體選擇都有可見標籤。
- [ ] 不以顏色作為唯一選取訊號；按鈕同時使用反相、邊框或文字。
- [ ] 200% 瀏覽器縮放仍可使用，文字不截斷、控制不重疊。
- [ ] 啟用 `prefers-reduced-motion: reduce` 後不自動旋轉，非必要轉場縮短。
- [ ] 使用 Windows Narrator、NVDA 或 VoiceOver 快速巡覽主要區域與控制名稱。

## SEO 與靜態網站檢查

- [ ] `lang="zh-Hant"`、標題、description、canonical 與 Open Graph 完整。
- [ ] `robots.txt` 與 `sitemap.xml` 可由網站根目錄取得。
- [ ] 正式部署前將 canonical 和 sitemap 網址換成實際網域。
- [ ] 重新載入任何必要入口不依賴後端路由改寫。
- [ ] CSS、JavaScript、SVG、XML 回傳正確 MIME 類型。
- [ ] 伺服器拒絕上層路徑及 `.env`、`.git` 等隱藏檔案。

## 通過標準

- `npm run verify` 零失敗。
- 桌機、平板、手機基準尺寸完成 B01–B08，沒有 console error 或水平溢位。
- 所有首版規格、八組色彩、跨語系文字、零件說明與本機保存可重現。
- 沒有提交 `.env`、憑證、token、私人金鑰或未授權素材。
- 嚴重度 Critical／Important 的程式碼審查意見均已修正或有明確說明。
