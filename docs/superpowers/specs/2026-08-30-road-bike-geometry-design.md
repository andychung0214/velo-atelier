# 真實公路車幾何與零件標示設計規格

## 核准基準

- 以使用者提供的「照片 3」作為傳統競賽公路車的輪廓與比例基準：700C 雙輪、接近水平的上管、短頭管、標準雙三角車架、彎把、座墊與 C 夾煞安裝位置。
- 以「照片 2」作為零件名稱與箭頭位置的語意對照，不採用其中的人物、背景或插畫風格。
- 不複製 MASI、Mercury 或其他品牌名稱、圖樣及商業外觀；模型維持 Velo Atelier 原創識別。

## 問題根因

- 既有輪距為輪徑的約 2 倍，遠高於常見公路車比例，使車體橫向過長。
- 五通高度幾乎與輪軸相同，缺少公路車應有的五通下沉。
- 頭管接近一個輪胎半徑，造成不自然的塔狀前端。
- 頭管網格被放在 `fork` 群組內，點選會錯誤顯示「前叉」。
- 水壺架、煞車與線管使用固定世界座標，切換車架時不會跟隨實際車管與安裝點。

## 幾何設計

- 使用純 JavaScript 幾何資料模組集中定義輪徑、前後輪軸、五通、座管頂端、頭管上下端、前叉冠與煞車安裝點。
- 競賽型基準採輪徑 1.64、輪距 2.50、五通下沉 0.18；輪距／輪徑應落在 1.48–1.62。
- 座管角應落在 72–75 度、頭管角應落在 70–74.5 度、頭管長度應落在輪徑的 18–28%。
- `race`、`aero`、`endurance` 共用輪軸與雙三角拓樸，只以合理幅度調整 stack、reach、管徑與上管斜率。
- 水壺架以頭管下端至五通的下管線段內插定位；機械變速線與煞車依車架安裝點衍生。

## 零件語意

- `frame`：座管、頭管、後上叉、後下叉、五通殼與連接橋。
- `topTube`：只有上管與上管飾線。
- `downTube`：只有下管與車架文字。
- `fork`：前叉冠與左右叉腳；頭管不得歸入前叉。
- `wheelset`：前後輪胎、輪框、輻條、花鼓與軸心。
- `brake`：碟盤與卡鉗，或前後 C 夾煞；安裝點必須靠近輪轂或輪圈上緣。
- `crankset`、`cassette`、`drivetrain`：分別對應曲柄齒盤、飛輪與鏈條／前後變速器。
- `cockpit`、`barTape`、`seatpost`、`saddle`、`bottleCage`：各自只包含其可說明的實體零件。

每個代表性網格都必須有穩定的 `userData.componentRole`，並由最近的 `partId` 祖先決定點選說明。測試須驗證角色與 `partId` 的對應，避免外觀正確但標示錯誤。

## 驗收

- 側面視角可辨識為傳統競賽公路車，不再有過長輪距、過高頭管或漂浮水壺架。
- 三種車架皆符合幾何範圍，切換輪組、碟煞／C 夾煞與變速形式不破壞結構。
- 點選頭管顯示車架、點選叉腳顯示前叉；主要零件的實際點選與說明標題一致。
- `npm test` 全數通過；桌機側視與三分之四視角、390px 行動版皆完成瀏覽器驗證。
